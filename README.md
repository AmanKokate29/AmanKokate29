### 1. FitVerse – AI-Driven Fitness & Pose Correction System

An AI-powered fitness platform for workout tracking, exercise pose analysis and personalized fitness recommendations.

- Real-time tracking of 33 body landmarks using MediaPipe.
- Exercise pose analysis and correction.
- Repetition counting across 10+ exercises.
- Personalized fitness recommendations.

**Technologies:** Python, OpenCV, MediaPipe

[View Project →](https://github.com/AmanKokate29/FITVERSE-AI-DRIVEN-REAL-TIME-POSE-CORRECTION-AND-FITNESS-RECOMMENDATION-SYSTEM)

A Django-based medicine recommendation system using machine learning and TF-IDF to process symptom-medicine records.

- TF-IDF-based data processing.
- Medicine recommendations based on symptoms.
- Data management using SQLite and Django ORM.

**Technologies:** Python, Django, Scikit-learn, SQLite

[View Project →](https://medi-match-rho.vercel.app/)
